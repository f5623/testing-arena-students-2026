Mögliche Fälle

1- (city, time, temperature) Reihenfolge ist wichtig

2- time is int

3- temperature is float (Celcius)

4- ":" steht für time

5- Stunde ist 0-23

6- Minute is 0-59

7- in ungültigen Fällen bekommt man "ValueError"

8- Stunde kann nicht negativ sein

9- Minute kann nicht negativ sein

10- Time kann nicht negativ sein

11- -60 <= temperature <= 60

12- line muss ein String sein, sonst ValueError

13- line muss 3 Teile haben

14- line muss mit ";" getrennt sein

15- line darf keine Führende und nachfolgende Leerzeichen haben 

16- bis hier "Der Stadtname darf nach dem Entfernen von Leerzeichen nicht leer sein."
